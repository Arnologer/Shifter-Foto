# 🚀 Инструкция по запуску Poster Cutter

## Установка зависимостей

```bash
pip install -r poster-cutter/requirements.txt
```

Или вручную:
```bash
pip install Pillow
```

**Для GUI версии также требуется Tkinter:**
- **Windows**: уже встроен в Python
- **macOS**: уже встроен в Python
- **Linux (Ubuntu/Debian)**: 
  ```bash
  sudo apt-get install python3-tk
  ```
- **Linux (Fedora/RHEL)**:
  ```bash
  sudo dnf install python3-tkinter
  ```

---

## 🖥️ Запуск GUI версии (рекомендуется)

Простой интерфейс с кнопками и превью:

```bash
python poster_cutter_gui.py
```

### Как использовать GUI:
1. Нажмите **"📂 Загрузить фото"** и выберите изображение
2. Укажите количество колонок и рядов (например, 4×6)
3. Выберите формат бумаги (A4, A3 и т.д.)
4. Настройте перекрытие (по умолчанию 10 мм)
5. Нажмите **"✂️ Нарезать и сохранить"**
6. Выберите папку для сохранения
7. Готово! Распечатайте файлы и склейте плакат

## 💻 Запуск консольной версии

Для продвинутых пользователей:

```bash
cd poster-cutter
python poster_cutter.py <путь_к_фото> -c <колонки> -r <ряды> [опции]
```

### Примеры команд:

**Базовый пример (нарезка на 4×6 листов А4):**
```bash
python poster_cutter.py my_photo.jpg -c 4 -r 6
```

**С автоматическим расчетом рядов:**
```bash
python poster_cutter.py image.png -c 4 --auto
```

**Формат А3 с перекрытием 15 мм:**
```bash
python poster_cutter.py photo.jpg -c 4 -r 6 --paper a3 --overlap 15
```

**В свою папку с своим шаблоном имен:**
```bash
python poster_cutter.py vacation.jpg -c 3 -r 4 -o ./my_poster --pattern "part_{row}_{col}.jpg"
```

### Все параметры консольной версии:

| Параметр | Описание |
|----------|----------|
| `input` | Путь к входному изображению (обязательно) |
| `-c, --cols` | Количество колонок (листов по горизонтали) |
| `-r, --rows` | Количество рядов (листов по вертикали) |
| `-p, --paper` | Формат бумаги: a0, a1, a2, a3, a4, a5, a6 (по умолчанию: a4) |
| `--dpi` | Разрешение в DPI (по умолчанию: 300) |
| `--overlap` | Перекрытие в мм для склейки (по умолчанию: 10) |
| `--pattern` | Шаблон имени файла (используйте {row}, {col}) |
| `--auto` | Авто-расчет пропорций |
| `-o, --output` | Папка для сохранения (по умолчанию: ./output) |

## 📝 Советы по печати

1. **Печатайте в масштабе 100%** (без масштабирования, без "fit to page")
2. **Отключите автоматическое выравнивание** в настройках принтера
3. **Используйте качественную бумагу** (плотность от 150 г/м²)
4. **Обрезайте поля** только с одной стороны каждого листа (кроме правого нижнего)
5. **Склеивайте внахлёст** используя указанное перекрытие (10-15 мм)

## ❓ Частые проблемы

### "Ошибка: Файл не найден"
Проверьте путь к файлу. Используйте абсолютный путь или убедитесь, что файл в текущей папке.

### "Неверный формат бумаги"
Доступные форматы: a0, a1, a2, a3, a4, a5, a6 (регистр не важен)

### "Необходимо указать --cols или --rows"
Укажите хотя бы один параметр размера. Например: `-c 4` или используйте `--auto`

### GUI не запускается
- Убедитесь, что установлен Tkinter (см. выше)
- На Linux проверьте переменную окружения DISPLAY
- Попробуйте консольную версию вместо GUI

## 🎯 Пример рабочего процесса

1. Есть фотография 3000x4000 пикселей
2. Хотите плакат размером 4 листа А4 в ширину и 6 в высоту
3. Загружаете фото в GUI
4. Указываете: Колонки=4, Ряды=6, Бумага=A4, Перекрытие=10мм
5. Получаете 24 файла (poster_page_01_01.png ... poster_page_06_04.png)
6. Печатаете все файлы на А4
7. Обрезаете и склеиваете
8. Готовый плакат размером примерно 84x119 см (4x6 листов А4)

Приятной печати! 🖨️✨

# 🖼️ Photo Tile Cutter

Мини-приложение для нарезки фотографий на плитки для печати больших плакатов на обычном принтере.

## 📖 Описание

Это приложение позволяет загрузить изображение и автоматически разбить его на несколько листов формата А4 (или другого заданного размера) для последующей печати и сборки в большой плакат.

**Пример использования:**
- У вас есть фотография в разрешении А4
- Вы хотите распечатать плакат размером 4×6 листов А4
- Приложение автоматически разделит изображение на 24 части (4 по горизонтали × 6 по вертикали)
- Каждая часть сохраняется как отдельный файл для печати

## ✨ Возможности

- 📤 Загрузка изображений в популярных форматах (JPG, PNG, TIFF)
- 📐 Настройка количества листов по горизонтали и вертикали
- 📏 Выбор формата бумаги (А4, А3, Letter и др.)
- ➕ Добавление полей для склейки (нахлёст)
- 🖨️ Генерация готовых к печати файлов

- 🔒 Обработка изображений локально (без отправки на сервер)

## 📋 Как использовать

1. **Загрузите изображение**
   - Перетащите файл в область загрузки или нажмите кнопку "Выбрать файл"

2. **Настройте параметры**
   - Укажите количество листов по горизонтали (например, 4)
   - Укажите количество листов по вертикали (например, 6)
   - Выберите формат бумаги (по умолчанию А4)
   - При необходимости настройте размер полей для склейки

3. **Предпросмотр**
   - Просмотрите, как изображение будет разделено на части
   - Убедитесь, что важные элементы не попадут на границы реза

4. **Скачайте результат**
   - Нажмите кнопку "Скачать все листы"
   - Получите ZIP-архив с готовыми к печати файлами

5. **Печать и сборка**
   - Распечатайте каждый лист на принтере
   - Аккуратно обрежьте поля (если добавлены)
   - Склейте листы в единый плакат

## ⚙️ Настройки

### Форматы бумаги
- **А4** (210 × 297 мм) — стандартный вариант
- **А3** (297 × 420 мм) — для больших принтеров
- **Letter** (8.5 × 11 дюймов) — американский стандарт
- **Custom** — пользовательские размеры

### Поля для склейки
Рекомендуется добавлять 10-20 мм полей для удобной склейки:
- **Без полей** — максимальное использование площади
- **5 мм** — минимальный нахлёст
- **10 мм** — рекомендуемый вариант
- **20 мм** — для большой точности сборки

## 💡 Советы по использованию

1. **Качество изображения**
   - Используйте изображения с высоким разрешением для лучшего качества печати
   - Минимальное рекомендуемое разрешение: 300 DPI

2. **Ориентация листов**
   - Учитывайте ориентацию принтера (портретная/ландшафтная)
   - Приложение автоматически подстроится под выбранный формат

3. **Нумерация листов**
   - Каждый лист помечается номером (например, "1 из 24")
   - Это упрощает сборку большого плаката

4. **Тестовая печать**
   - Перед печатью всего плаката распечатайте 1-2 листа для проверки
   - Убедитесь в правильности цветов и масштаба

## ❓ FAQ

**В: Можно ли печатать на принтере с непостоянными полями?**
О: Да, рекомендуется добавить дополнительные поля в настройках для компенсации ограничений принтера.

**В: Какой максимальный размер плаката поддерживается?**
О: Технически ограничений нет, но рекомендуется не превышать 10×10 листов для удобства сборки.

**В: Работает ли приложение офлайн?**
О: Да, после загрузки страницы все вычисления происходят локально в браузере.
